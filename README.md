# عيادة دنتال كير - نظام حجز ذكي

مشروع ويب متكامل لإدارة مواعيد عيادة أسنان باستخدام Flask.

## المميزات
- حجز تلقائي لأقرب موعد (الأحد-الخميس 9ص-5م)
- اختيار نوع الخدمة (استشارة/حالة طارئة/عملية)
- لوحة تحكم للإدارة (إضافة/حذف/تعديل)
- طباعة جدول أسبوعي بصيغة PDF
- دعم كامل للغة العربية
- نظام فواتير تلقائي (إكمال موعد → فاتورة + خدمات قابلة للتعديل + PDF عربي)
- إرسال الفواتير والتذكيرات للمرضى عبر البريد الإلكتروني (Gmail SMTP)
- تذكير تلقائي يومياً الساعة 9 صباحاً لمواعيد الغد + زر تذكير يدوي
- تأكيد الحجز بالإيميل فور الحجز

## تشغيل المشروع
1. ثبّت المكتبات: `pip install -r requirements.txt`
2. شغّل: `python app.py`
3. افتح المتصفح على `http://127.0.0.1:5000`

## الدخول للوحة الإدارة
- الرابط: `/admin/login`
- كلمة المرور الافتراضية: `admin123`

## تفعيل البريد الإلكتروني
1. ادخل `/admin/settings` من لوحة التحكم
2. ضع بريد Gmail + كلمة مرور تطبيق (من إعدادات أمان Google)
3. أرسل بريداً تجريبياً للتأكد
4. التذكير التلقائي يعمل يومياً 9:00 صباحاً لمواعيد الغد
